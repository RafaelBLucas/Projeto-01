O QUE É CSS?

É a linguagem usada para estilizar uma página web, descrevendo como os elementos HTML deve ser exibido. Seja na tela,papel ou em outras mídias, economizando trabalho e ajuda no controle do layout de várias páginas simultaneamente.

IMPORTANTE: Folha de estilo externa são armazenandas em arquivo CSS.
